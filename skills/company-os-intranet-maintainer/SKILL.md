# Company OS intranet maintainer

1. Read the repository `AGENTS.md` and the central Company OS intranet registry.
2. Determine whether changed files match a registered page's source patterns.
3. Run only the registered page generator. Never hand-edit generated HTML.
4. Run the declared local-link and freshness checks.
5. Record the maintenance result.
6. Do not approve, schedule, dispatch, publish, delete, or relocate content.
7. Report unowned or ambiguous pages for human review.
